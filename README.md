# Road Companion
A mobile application for road safety, developed for The National Academy for Road Safety and Security.


# Overview
a mobile app designed to assist drivers, improve road safety, and simplify traffic law learning. The app provides:

- Traffic Law Consultation – Learn and search for Algerian road regulations.
- Interactive Tests & Exams – Train and evaluate driving knowledge.
- GPS Navigation System – Get real-time routes and avoid traffic.
- Incident Reporting – Report road hazards and view nearby incidents.
- Roadside Assistance – Request help in case of breakdowns.

## Getting Started
- Clone the repository:
  git clone https://github.com/Amina3524/road_companion_app.git
  Change dir to the road_companion_app
- Run `flutter pub get` to install dependencies.
- Run `flutter run` to start the app.
- Set Up Firebase (you will use the firebase project I've shared with you)

## How the Team Should Work (To Avoid Issues):
- Before making changes, always pull the latest updates: git pull origin
- Work on a separate branch (not directly on the main!!):  git checkout -b feature-branch-name
- After making changes, commit properly:
  git add
  git commit -m "..."
- Push your branch to GitHub: git push origin feature-branch-name
- Create a Pull Request (PR) and request a review before merging.
