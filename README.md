# Road Companion

A mobile application for road safety, developed for The National Academy for Road Safety and Security.

## Features
- Traffic Law Consultation
- Incident Reporting
- Roadside Assistance
- Real-Time GPS Navigation

## Getting Started
- Clone the repository.
- Run `flutter pub get` to install dependencies.
- Run `flutter run` to start the app.
